Arrange the other screens around one task

Monthly plan: month + position → Budgets / Bills → selected list → relevant Add action.
Capture: Cancel + “Add expense” → amount → category → account → date → optional details → keyboard-aware Save.
Accounts: title + Add → compact total → account list → account detail and maintenance.
Report: title + period → Overview / Spending / Calendar → focused analysis.
Settings: backup/storage status → grouped setting rows → individual configuration screens.

Important correction before redesign: “months cover” currently uses spending from the dashboard's selected period. It needs an independent, explicitly monthly baseline. Do not treat the proposed layout as approval of the existing calculation.
